근무표 · 월말 정산표

A / P / 년 입력 → 주 단위(일~토) 첫 빈칸은 주휴, 두 번째 빈칸은 휴무 → 엑셀 다운로드
입력값은 자동 저장됩니다. 엑셀/구글시트의 여러 셀을 복사한 뒤 원하는 시작 칸에서 Ctrl+V 하면 표 형태 그대로 붙여넣을 수 있습니다. 빈칸은 비워두세요. 년은 연차로 인식해 빨간색으로 표시합니다.
월초 첫 주가 전월과 이어지는데 전월 데이터가 저장되어 있지 않습니다. 이 경우 월초 첫 주는 현재 월에 보이는 날짜만 기준으로 주휴/휴무를 판단합니다.
오는 A(오전) 횟수, 후는 P(오후) 횟수입니다. 계는 원래 근무표에서 값이 입력된 칸(A/P/년 등)만 세며 자동 생성된 주휴·휴무는 포함하지 않습니다.

공휴일 목록 YYYY-MM-DD,공휴일명

날짜만 입력해도 됩니다. 한 줄에 하나씩 입력하세요. 저장 후 해당 날짜 열 전체가 빨간색으로 표시됩니다.

사용 방법

1. 연도·월을 고르고 달력 적용
2. 근무표에 A / P / 년 등을 입력
3. 월말 정산표 만들기 클릭
4. 엑셀 저장 클릭
5. 다음에 이어서 작업할 때는 엑셀 불러오기

색상 규칙: 토요일 파랑 / 일요일 빨강 / 공휴일 빨강 / 연차(년) 빨강
